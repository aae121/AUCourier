# AUCourier

**AUCourier** is an Android app developed with **React Native** and **JavaScript** to facilitate package delivery services within the campus environment. The app provides a streamlined process for students, staff, and faculty to manage and track intra-campus deliveries efficiently.

> **Note:** Due to GitHub's file size restrictions, the full project file is available on Google Drive. You can download it [here](https://drive.google.com/file/d/1_LECyQnEHCJYAHXAoX-U5ayiflt-_OH6/view?usp=drivesdk).

## Features

- **User Registration & Authentication:** Secure login and registration for users, enabling personalized delivery requests.
- **Package Management:** Allows users to request, schedule, and view their package details.
- **Real-time Tracking:** Enables users to track their packages live on a campus map.
- **Notifications:** Push notifications for real-time updates on package status.
- **Feedback System:** Users can rate and leave feedback for the courier service to ensure high-quality standards.

## Tech Stack

- **Frontend:** JavaScript, React Native
- **Backend:** Node.js (Express)
- **Database:** MongoDB for user data, package information, and delivery records
- **APIs:** Google Maps API for geolocation and real-time tracking
- **Push Notifications:** Firebase Cloud Messaging (FCM)
